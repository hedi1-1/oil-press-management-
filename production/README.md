# 📋 Module de Gestion de Production - PressIQ

## 📖 Description

Le module **Production** gère l'ensemble du cycle de production d'huile d'olive : de la planification initiale jusqu'à la génération des rapports. Il comprend 7 onglets pour suivre chaque étape du processus.

---

## 📑 Les 7 Onglets

### 1. 📋 Planification
C'est ici que vous configurez une nouvelle production :
- Choisir la date de production
- Entrer la quantité d'olives (en kg)
- Sélectionner le type de pressage (à froid ou à chaud)
- Ajouter des notes si nécessaire
- Cliquer sur **"Planifier la production"** pour valider

### 2. ▶ Lancement
Page de contrôle de la production :
- Affiche l'état actuel (prêt, en cours, terminé)
- Montre l'heure de démarrage
- Barre de progression (0% à 100%)
- Deux boutons : **Démarrer** (vert) et **Arrêter** (rouge)

### 3. 📍 Suivi
Permet de surveiller la production en temps réel :
- Voir la production en cours
- Tableau d'historique avec les productions passées (date, quantité d'olives, huile produite, statut)
- Zone pour ajouter des observations
- Bouton pour mettre à jour les informations

### 4. 📊 Rendement
Calcule automatiquement le rendement de production :
- Affiche la quantité d'olives utilisée
- Entrer le volume d'huile obtenu
- Le système calcule le pourcentage de rendement
- Affichage avec une barre de progression et un grand badge vert

**Formule** : Rendement (%) = (Huile en litres / Olives en kg) × 100

### 5. ✓ Qualité
Évaluation de la qualité de l'huile produite :
- Choisir la qualité : Excellente, Bonne, Moyenne ou Faible
- Cocher si l'huile est conforme aux normes
- Ajouter des remarques sur la qualité (acidité, couleur, goût...)
- Bouton **"Valider la qualité"** pour enregistrer

### 6. 📄 Rapports
Génération de rapports de production :
- Affiche un résumé de la production
- Zone de texte avec le contenu détaillé du rapport
- Date de génération
- Deux boutons : **Générer rapport** et **Exporter PDF**

### 7. 🔍 Recherche & Tri
Retrouver facilement les productions passées :
- **Recherche** : taper un mot-clé (date, statut, quantité...) et choisir le champ de recherche
- **Tri** : sélectionner le critère (date, quantité, rendement...) et l'ordre (croissant/décroissant)
- **Tableau de résultats** avec toutes les informations
- Compteur de résultats et bouton pour effacer la recherche

---

## 🎨 Interface

L'interface utilise un design professionnel avec :
- **Couleurs** : Vert foncé et or pour le thème
- **En-tête** : Logo, titre "production management" et bouton retour
- **Indicateur** : "● EN LIGNE" en haut à droite
- **Boutons** : Verts pour les actions principales, rouges pour arrêter, dorés pour exporter

---

## 💡 Utilisation typique

1. **Planification** → Configurer une nouvelle production
2. **Lancement** → Démarrer la production et suivre la progression
3. **Suivi** → Ajouter des observations pendant la production
4. **Rendement** → Calculer le rendement obtenu
5. **Qualité** → Évaluer et valider la qualité de l'huile
6. **Rapports** → Générer un rapport complet
7. **Recherche** → Retrouver les anciennes productions
